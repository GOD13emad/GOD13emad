## What to provide for a useful quote

1. **Goal and acceptance criteria:** desired results and how correctness will be judged.
2. **Inputs:** geometry and units, material properties, operating range, loads, boundary/initial conditions, data files, and source code or reference publications if applicable.
3. **Deliverables:** editable code/model, processed results, charts, video/screenshots, and report language/format.
4. **Validation requirements:** reference measurements or published comparison, allowable numerical error, mesh/time-step convergence expectations.
5. **Practical constraints:** deadline, target software/version, platform, usage rights, and whether confidential materials must remain private.
